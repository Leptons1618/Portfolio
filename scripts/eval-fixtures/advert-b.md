# Applied AI Engineer — Cobalt Systems

Cobalt Systems builds an internal assistant for field engineers. The role is to
ship retrieval and evaluation for that assistant.

## The work

- Build retrieval over technical manuals and service records.
- Design evaluation sets and run them on every model change.
- Own the tool loop: which functions the model may call, and what it may not do.
- Work with one product engineer and one designer.

## Requirements

- Two or more years shipping LLM applications.
- Hands-on evaluation experience: datasets, scoring, regression runs.
- Python and TypeScript.
- Comfortable saying no to a model change that cannot be measured.

## Nice to have

- Computer vision for document parsing.
- Cloudflare Workers or another edge runtime.

Location: remote in India. Posted 2026-11-02.
