# Senior Backend Engineer — Northwind Ledger

Northwind Ledger builds accounting software for independent retailers. We are
looking for a senior backend engineer to own the ledger service.

## What you will do

- Design and operate the double-entry ledger API.
- Work with Postgres, Python and a small amount of Go.
- Own correctness: reconciliation, idempotency and audit trails.
- Review code and mentor two mid-level engineers.

## Requirements

- Five or more years building production backends.
- Strong SQL and relational modelling.
- Experience with financial or other correctness-critical systems.
- Comfortable with distributed transactions and idempotent writes.

## Nice to have

- Kubernetes in production.
- Event-driven systems with Kafka.
- Public writing about backend design.

Location: Bengaluru, hybrid (three days in office). Compensation discussed.
