// WHAT'S WORKING

Documented token system

Ramps, motion durations, spacing, and shadows are named tokens with written rationale. Dark mode is expressed twice by design so OS-following and forced modes both resolve correctly, and print is excluded from dark entirely.

Identity over category reflex

Ivory paper, Instrument Serif display, terracotta accent, grain overlay, angled-sweep primary button. No SaaS purple, no gradient hero, no pill-button default. The two-second "AI made that" test passes.

Interaction engineering

Custom combobox keeps a full keyboard model and native fallback; filters persist in the URL with a polite live region; the Ask widget degrades to nothing without JS and builds every model response as text nodes.

// PRIORITY ISSUES
P0 · HIGH · MOTION / ACCESSIBILITY

Case-study hero video autoplays and loops, ungated and unstoppable

`src/layouts/CaseStudyLayout.astro:29`: `<video src={heroVideo} autoplay muted loop playsinline>`. Self-starting looping video is an escalation trigger: vestibular-triggering motion that runs regardless of `prefers-reduced-motion`, with no `controls`, poster, or pause affordance anywhere. Every other animated element on this site guards itself; this is the exception, on the page type most likely to carry showreel footage.

FIX: Gate autoplay behind `(prefers-reduced-motion: no-preference)`, add a visible pause/play control, ship a poster frame so reduced-motion visitors get a still.
P0 · HIGH · COLOR / ACCESSIBILITY

Faint-text token fails contrast at its actual sizes, site-wide

`src/styles/theme.css:108` sets `--color-text-faint: var(--color-neutral-600)`: light `#a49c8c` on surface = 2.43:1; dark `#6a6459` = 3.10:1. Its consumers are `.card-meta` (11px, `global.css:629`) and `figcaption` (`global.css:143`) — project-card action rows, journal dates, figure captions. Small text on insufficient ground is an escalation trigger, repeated across every listing page.

FIX: One token change — point faint at a step clearing 4.5:1 in both ramps (light ≈ #8a8172, dark ≈ #8f887b), or re-point consumers at muted (5.17:1 / 5.91:1). Highest leverage per line in this report.
P1 · MEDIUM · ACCESSIBILITY

Eyebrow labels are h6 elements, scrambling the heading outline

Six public-page eyebrows render as `<h6>` before their section's real headings (index.astro:32,59,85,101; about.astro:8; journal/index.astro:50), so screen-reader heading navigation reads Software Engineer → Building ML systems… then jumps Case Studies → Deep dives. Purely decorative labels sit inside the document outline they do not belong to.

FIX: Swap to `<p class="eyebrow">`. Existing scoped rules target the class, so rendering is unchanged.
P1 · MEDIUM · RESPONSIVE / INTERACTION

Sub-16px form fields trigger iOS focus zoom; several targets miss the touch floor

`.input` ships 14px (`global.css:467`) and the Ask textarea 13px (`AskWidget.astro:1496`); focusing either on iOS Safari auto-zooms the viewport and breaks layout. Meanwhile the mode toggle is a 28px square (`ThemeToggle.astro:114`), Ask icon buttons 26px, send button 34px, and `.tag-button` chips roughly 22px tall — all under 44×44, adjacent enough to merge under a thumb.

FIX: Raise input font-size to 16px on coarse pointers/narrow screens; expand hit areas via padded ::before overlays without changing visual size.
P1 · MEDIUM · ACCESSIBILITY

No skip link; keyboard users re-tab the nav on every page

`BaseLayout.astro:69-71` renders Header, main, Footer with no skip link and no `main` id target. Eight tab stops (brand, five links, two toggles, CTA) stand between every keyboard arrival and the content — repeated on each of the site's pages.

FIX: Visually-hidden "Skip to content" link as the first focusable element, targeting `<main id="main">`.
P2 · LOW

Two polish items

Closing banner body copy sits at 90% opacity on terracotta = 4.32:1, just missing AA for normal text (`index.astro:222`). The card kicker runs at 10px uppercase (`global.css:603`), the smallest type on the site — passing contrast but straining legibility.

FIX: Full-opacity banner text; 11px floor on the kicker, matching `.tag`.
